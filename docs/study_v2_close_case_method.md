# Study v2 Close-Case Matching Method

The primary match is constructed before neighbor outcomes are attached. It exact-matches incident
family, Race/Sprint session, and guideline regime, then measures distance on reviewed first-lap,
wet-track, Safety Car restart, attacker-line, and overlap context. Rows from the same incident are
never neighbors. A case needs five different-incident neighbors.

Fault finding, penalty, damage, repair, retirement, finish, and points are forbidden match inputs.
Tests flip every neighbor outcome and verify that the neighbor graph does not change. Outcomes are
joined only after matching to show the local sanction rate and outcome mix.

Responsibility can be used only in a separate fault-conditioned sanction population after a fault
finding has been reviewed. This asks whether sanctions varied among cases with the same fault class;
it is not the primary conduct match.

The current build uses machine-extracted context candidates and is therefore a feasibility artifact.
Its release status remains withheld until the human context worklist is completed. Sparse exact-match
groups remain low support rather than being widened after results are seen.
