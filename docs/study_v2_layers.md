# Study v2 Analytical Layers

Study v2 stores conduct, consequence, and sanction burden in separate tables. It does not convert
seconds, positions, grid places, points, damage, and retirement into one score.

The conduct layer contains the 346 model-reviewed primary adjudications and pre-outcome context
candidates. The consequence layer contains 411 driver records across 193 candidate collision
incidents. The sanction layer preserves nominal penalty units but leaves realized burden blank until
application timing or the correct future event is reviewed.

Persistent-pace screening uses only accurate green-flag, non-pit laps. It matches each participant
to a teammate on the same lap and compares the before/after change in their relative lap time. Of 52
timing-eligible records, 28 have enough exact matched laps. These estimates are not causal damage
effects: tyre offsets, traffic, strategy, weather, and unobserved car condition remain possible.

The proportionality gate requires independently reviewed conduct and harm evidence. It currently
releases zero full-corpus records. Model-reviewed fault and timing screens are retained as research
inputs, not promoted to final fairness findings.
