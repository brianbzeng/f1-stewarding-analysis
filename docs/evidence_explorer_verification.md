# Evidence Explorer Verification

## Build contract

The explorer is generated by `f1stewards build-explorer` from the project DuckDB database plus the
versioned adjudication, sanction-impact, victim-harm, and independent-review CSVs. `src/f1stewards/explorer.py` assembles
the evidence records, validates release invariants, and writes `explorer/index.html`.

## Automated controls

`tests/test_explorer.py` verifies:

- Python filter counts against a DuckDB reference query;
- rejection of unsupported nationality filtering;
- driver-name and event-date guideline URL resolution;
- official decision URL enforcement;
- 2025 guideline clause and source enforcement;
- accessible tabs, live filter status, and embedded data;
- release gating on both resolved review targets and reconciled curated rows.

The project-wide quality run also executes the existing source, parser, schema, regulatory,
readiness, and counterfactual controls. The generated payload is additionally checked against the
real pilot database for record counts, source URLs, guideline lineage, and excluded nationality
fields.

## Manual browser checklist

Before treating a generated artifact as a release candidate:

1. Confirm the header says `provisional` until independent review and reconciliation are complete.
2. Navigate all six tabs with a mouse and the left/right arrow keys.
3. Apply and reset multiple decision filters; compare the live result count with the table rows.
4. Expand evidence for examples from 2019, 2023, and 2025 and open each official link.
5. Download the filtered CSV and confirm stable adjudication IDs and official source URLs remain.
6. Confirm the comparable-case view publishes no ranking or model estimate while gated.
7. Check the impact table keeps mechanical and non-estimable records visibly distinct.
8. Check the harm table keeps responsibility, damage evidence, forced stops, persistent pace, and net
   effect visibly distinct.
9. Review the data-quality cards and build-lineage timestamps for the current run.

## Current pilot disposition

suitable for substantive claims about steward consistency, nationality effects, or error rates.
Fifteen review targets now include two mirrored victim-harm pilot rows; the full 2018-2025 corpus has not been
built.
